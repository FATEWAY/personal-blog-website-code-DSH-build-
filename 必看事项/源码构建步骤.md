一、本地终端调试步骤：

1、环境下载node,js
2、终端——cd源码目录
3、输入“npm ci --include=dev”构建node_modules文件
4、输入“npm run build”构建.next 目录
5、输入“npm start”运行网站

二、服务器（类宝塔面板的管理器）部署步骤

1、前置要下载Ngnix和node.js
2、将源码放到服务器某个目录
3、新建一个php项目，都默认即可，但是需填入域名或者网站。（即目标建立一个代理）
4、为这个php项目申请一个证书（开发443端口，要不然很麻烦）
5、可以选择先上传源码在服务器端执行"一"中的3、4步骤编译，也可以在本地执行编译"一"中的3、4步骤然后上传到服务器。
6、添加node项目，选择源码目录,启动选项选择sever.js。包管理器选择npm。建立完成后可添加任意端口号（例如3000，但有些不能）
7、添加反代理，将php的端口指向node项目端口。
8、最后修改一下反代理的配置文件，将
            "proxy_set_header Host 127.0.0.1;"
-------修改为----->
            proxy_set_header Host $host;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Forwarded-Host $host;
原因：不改配置可能访问不了后台
