一、本地终端调试步骤：

1、环境下载 Node.js
2、终端——cd "deepseek build website"（本地源码目录）
3、输入“npm ci --include=dev”构建 node_modules
4、输入“npm run build”构建 .next 目录
5、输入“npm start”运行网站

\************************************************\

二、服务器（类宝塔面板的管理器）部署步骤

1、前置要安装 Nginx 和 Node.js
2、将源码放到服务器某个目录，例如 /www/wwwroot/fateway
3、新建一个 PHP 项目，都默认即可，但是需填入域名或者网站（即目标建立一个代理）
4、为这个 PHP 项目申请一个证书（开放 443 端口，要不然很麻烦）
5、可以选择先上传源码，在服务器端执行“一”中的 3、4 步骤编译；也可以在本地执行编译后上传到服务器
6、添加 Node 项目，选择源码目录，启动文件选择 `server.js`，包管理器选择 npm。建立完成后可添加端口号（例如 3000，但有些端口不能用）
7、添加反向代理，将 PHP 项目的流量指向 Node 项目端口
8、最后修改反向代理配置，将
            "proxy_set_header Host 127.0.0.1;"
-------修改为----->
            proxy_set_header Host $host;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_set_header X-Forwarded-Host $host;
原因：不修改可能导致后台登录提示“请求来源不受信任”
